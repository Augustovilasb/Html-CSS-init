## 📖 Sobre

Aqui foi o **início dos meus estudos em HTML e CSS** — e, na real, foi aqui que nasceu um brio de verdade por programação.

Sei que HTML e CSS não são programação em si, mas foi exatamente isso que **despertou em mim a vontade de programar**. Foi o primeiro lugar onde vi uma ideia virar algo na tela, e isso bastou pra me fazer querer ir mais fundo.

Este repositório reúne os primeiros projetos dessa fase, cada um na sua pasta.

## ▶️ Como abrir

Cada projeto é estático — sem instalação, sem build. É só abrir o `index.html` (ou `.html` principal) da pasta direto no navegador.
