# HTML & CSS Learning

The start of my studies in HTML and CSS, and where my interest in programming really began. This repository gathers the first static projects from that phase, each in its own folder.

## Projects

| Folder | What it is |
|--------|------------|
| [`ProjectAlura/`](ProjectAlura/) | Website built during the Alura course, the first project of all |
| [`GameProject/`](GameProject/) | Game landing page using HTML, CSS and a bit of JavaScript |
| [`ComunidadeBallerini/`](ComunidadeBallerini/) | Community page built to practice layout and styling |

## How to run

Every project is static, with no install and no build step. Open the main `.html` file of the folder directly in a browser.
